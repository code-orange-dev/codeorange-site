Highlights

1Diego's open lab: agent sessions you can read like a night sky

Observability, made visual. Guest speaker Diego (Argentina, 15 years in IT) built everything he showed with Claude Code. His open lab takes the telemetry a coding agent already produces and draws each session as a galaxy: the orchestrator in the middle, sub-agents around it, tools and hooks firing as lights between them. Colours mean something. A lot of red means too many guardrails are firing and the work is stuck. There is a second version for LangGraph.

Inside the lab

Agent constellationsConnect your own Claude Code with a plugin and watch your sessions live in the browser.
Protocols labMCP, agent to user, agent to agent, agent to business: each one animated message by message.
x402 pay per callA shopping agent pays 0.01 per call on a testnet, and you see the code run in real time.
Agentic AcademyFree and open courses: one track with no code, one for building agents. No login, no ads, funded by sponsors.

How it pays off: the lab is free. Clients see it, then ask for the same thing inside their own company. “You have to give something away in order to have something in return.”

2A cyborg company: agents at desks, humans accountable

A company you can walk through. Diego's startup shows a business as 3D buildings with departments inside. Each desk has an agent with a face and a job. You can see what it is doing, talk to it by voice, and read reports by department. The goal is to let non-technical people, and people with disabilities, work with agents.

3An agent pays for data over Lightning

Real sats, live. keypleb vibe coded a small demo before the call. The agent's job: write a live Bitcoin network briefing. To do it, it needs five answers (block height, fees, price, mempool, hashrate) and each one costs 10 sats. A phone wallet paid a 50-sat invoice, and the agent bought each answer by itself. No account, no card, no API key.

keypleb, on L402

A meme bot that earns zaps. The last demo was a Nostr account that posts memes made by an agent, with a Lightning address on its profile. If a post makes you laugh, you zap it and the sats land in an ecash wallet. Not L402, but the same idea: value for value, with a bot on one side.

Key takeaways

1. Agents can already hold and spend sats. Paying per call fits how agents work: model calls, data feeds, web search, compute, paywalled content, even a tiny fee to keep spam away.

2. Keep a human accountable. Budget caps, hooks that block broken rules and a signature for anything that matters. The more an agent can do, the more this counts.

3. Show your work to win work. Diego's lab is his portfolio. keypleb rebuilt the website, a dashboard and the ads for a small business with an agent, and that story is now the pitch for the next client.

Resources shared

Tools

  • Agent pay demo, Code Orange: the demo from the call: an agent buys five pieces of live Bitcoin data for 10 sats each over Lightning, with real sats or in practice mode
  • Paxel, Y Combinator: free tool that reads your local Claude Code, Codex or Cursor sessions and gives you a profile of how you build with agents
  • Claude Code, Anthropic: the coding agent Diego used for everything he showed, about 95% of the time in the desktop app
  • LangGraph, LangChain: agent framework; Diego built a second constellation view on top of its tracing tool, LangSmith
  • OpenRouter: one API for many models, with free tiers; used as a fallback in Diego's projects and for the Mandarin tutor
  • Antigravity, Google: agent-first code editor one developer uses for projects he does not plan to maintain by hand

Reading

  • L402, Lightning Labs: the protocol behind the demo: an HTTP 402 "payment required" answer, a Lightning invoice, and a token that proves you paid
  • Lightning agent tools, Lightning Labs (2026): "The agents are here and they want to transact": the toolkit that Pi402 and the Wavelength wallet build on
  • x402: pay-per-call for agents over HTTP 402 with stablecoins; Diego's lab runs it on a testnet next to MCP-style protocols
  • Model Context Protocol (MCP): the standard way to give an agent tools; one of the protocols animated step by step in Diego's protocols lab

Wallets

  • Minibits: ecash wallet with a Lightning address; it receives the sats in the agent pay demo and the meme bot's zaps
  • Cashu.me: ecash wallet in the browser, used for the 21-sat zap test
  • Wallet of Satoshi: the phone wallet that paid the 50-sat invoice live on the call
