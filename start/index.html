Where do you want to start?

Code Orange is free and hands-on. Pick the path that sounds like you and follow three steps. You can switch paths any time.

I’m new to Bitcoin

Understand what Bitcoin is, how it works and why it matters, with no jargon and no pressure.

  1. 1

    Come to Bitcoin Basics

    A friendly intro to keys, wallets and transactions. Bring questions, not experience.

    Bitcoin Basics →
  2. 2

    Read why self-custody matters

    A short read on why holding your own keys is the point of Bitcoin.

    Read the article →
  3. 3

    Join the Bitcoin Reading Club

    Read the classics together each month, from the whitepaper to the cypherpunks.

    Reading Club →

I want to hold my own bitcoin

Move off exchanges and set up a wallet you trust, step by step and hands-on.

  1. 1

    Do the Self-custody workshop

    Set up a wallet, back up your seed and send your first self-custody transaction with help in the room.

    RSVP on Discord →
  2. 2

    Go further: Sovereign Bitcoiner

    Run your own node, try multisig and plan inheritance so your bitcoin outlives you.

    Sovereign Bitcoiner →
  3. 3

    Protect your privacy

    Drop into the Privacy Track to learn PayJoin, Silent Payments, CoinJoin and ecash.

    Privacy Track →

I write code

Go from reading Bitcoin code to getting your own pull requests merged into real projects.

  1. 1

    Join the Decoding Bitcoin cohort

    Ten weeks on transactions, Script and Taproot, with weekly Discord sessions. Starts Mon 16 Nov.

    Decoding Bitcoin →
  2. 2

    Come to Code Review Club

    Review real Bitcoin pull requests with others every week and learn how open source works.

    RSVP on Discord →
  3. 3

    Make your first contribution

    Get your first pull request merged with help from the community, then apply for a Code Orange fellowship to go deeper.
