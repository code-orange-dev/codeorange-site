Every session ends with proof of work. Useful, not noisy.

Not "homework." Proof of work: a lab passing the official test vectors, a PR you built and tested, a reproduced bug, a docs fix, a pull request on an issue you checked is still open. Nothing goes upstream unless a maintainer would be glad to receive it. Over 12 sessions that compounds into a public contribution record no CV can fake.
