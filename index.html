FAQ

Common questions.

How much does it cost?

All Code Orange programs are free for accepted students. The school is funded through Bitcoin grants, donations, and partnerships.

Do I need prior coding experience?

rawBit and the Bitcoin Privacy Track expect comfort with a programming language. Bitcoin Basics, Sovereign Bitcoiner, OpenClaw, and Vibe Coding welcome curious beginners.

Can I join remotely?

Yes. Most sessions run online through Discord, with hands-on hardware sessions layered in where they help.

Can I run a workshop?

Yes. The curriculum is open source and the community can help with local adaptation, links, and promotion.
