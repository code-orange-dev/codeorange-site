Highlights

1A self-custody simulator, built by talking to an agent

Practise before it's real. Some people own a hardware wallet but are still too scared to move their bitcoin onto it. Andy built an interactive simulator so they can practise first, guided by a mentor character, with no real money at stake. He built it in Bolt: type (or say) what you want, click any element to change it, roll back from the history if you don't like the result, and publish with one button.

Missions, one after another

→
Withdrawfrom an exchange
→
Recoverreset, re-enter 12 words
→
Connectpair wallet software

Guard rails: click a button that isn't part of the step and the mentor says “let's stick to the plan”. Seed words can be typed straight in instead of scrolling letter by letter.

Feedback from the call. Make one rule impossible to miss: seed words go into the hardware wallet only, never into a website or software wallet, and explain why (it stops being cold storage). And add translations: Chinese-speaking Bitcoiners asked for it first. Missions run in order for now; letting people skip ahead and link back to earlier steps was another suggestion.

2The mempool as a fish tank, a beehive and a T-shirt factory

One prompt, one HTML file. A builder asked several AI models for a live Bitcoin transaction visualizer. One answer was a single HTML file that pulled live data from the mempool.space API and just worked. From there he kept adding ideas with a cheap model in OpenCode, committed to GitHub and let Vercel deploy each change.

3From finding issues to running a team of agents

An issue finder for Bitcoin open source. One builder scans about 50 Bitcoin repositories, analyses their open issues and good first issues, matches them to your skills from your GitHub account, and sends daily updates to Telegram. PayJoin was the first project he dug into.

One agent to talk to, many to do the work. Another builder is making his own Mac and iPhone app around an orchestrator. You speak to it, and it hands the task to the right agent and model.

The orchestrator pattern

Youspeak or type
→
Orchestratorpicks the agent
→
Builderwrites the code
→
Reviewerchecks it

Mix harnesses: the builder can run in Claude and the reviewer in Codex. Herdr does this in the terminal. A home server, reached from the phone through a Cloudflare Tunnel, keeps it private and runs nightly jobs.

Key takeaways

1. Speak, don't type. Rambling for two minutes into the microphone gives the agent more context than a short typed prompt, and it's faster. Superwhisper and Omarchy's dictation were both recommended.

2. Small and cheap goes a long way. A single HTML file and a free API made a fun, useful Bitcoin tool. Cheap models were good enough for most of the work, with a stronger model only when the agent got stuck. One organiser rebuilt a business website with bookings, SMS checks and newsletters in two days, then set up its ads the same way.

3. Payments are easy to hand to an agent. A Bitcoin tip button now sits on the workshop page, made with BTCPay Server on an Umbrel. Alby Hub was even quicker to wire up: give the agent the connection details and it gets done.
